Optional: sprites are included with this page, so you do not need to pick anything. If you prefer your own copy, note that Chrome and Edge will not let a website open folders under Program Files (they say "contains system files"), and the game usually lives there. If the picker refuses your Resources folder, copy the files named GJ_GameSheet*, PixelSheet_01*, GJ_ParticleSheet*, FireSheet_01* and bigFont* (the -uhd and -hd ones) into any other folder on your PC, and choose that folder here. Or use "Pick folder (other browsers)", which has no such limit but cannot remember the folder.

Songs play from your own computer: the game saves every song it downloads as <song id>.mp3 in %LOCALAPPDATA%\GeometryDash (paste that into the folder dialog's address bar). Newgrounds does not allow other sites to stream its audio, so this page never does. The lookup service is only used for the song's name and artist.
